■ このフォルダについて

public/assets/ に置いたファイルは、そのまま公開URLに出ます。
　例）public/assets/logo.jpg → https://（サイト）/assets/logo.jpg

つまり、ページから参照していなくても、URLを直接叩けば誰でも見られます。
**使わなくなった画像は、必ずこのフォルダから消してください。**

■ 今ここにあるファイルと、使われている場所

┌──────────────────┬────────────────────────────────────┐
│ ファイル名           │ 使われる場所                                       │
├──────────────────┼────────────────────────────────────┤
│ favicon.jpg        │ ブラウザのタブのアイコン（index.html）                  │
│ ogp.png            │ LINE・Slack・X に貼ったときのカード画像（index.html）    │
│ logo.jpg           │ トップ COMPANY セクション（Home.tsx）                 │
│ logo-cube.png      │ トップ STRENGTHS の立方体の天面（Home.tsx）            │
│ logo-white.png     │ オープニング演出（Opening.tsx）                       │
│ logo-letters.png   │ フッターのロゴ・文字部分（Footer.tsx）                  │
│ logo-mark.png      │ フッターのロゴ・◆部分（Footer.tsx）                    │
│ line-qr.png        │ お問い合わせページの公式LINE QR（Contact.tsx）          │
└──────────────────┴────────────────────────────────────┘

・ロゴが2枚（letters と mark）に分かれているのは、フッターでマウスを乗せたとき
　文字だけ色を変え、◆はオレンジのまま残すためです。1枚だと分けられません。
・ogp.png は手描きではなく生成物です。作り直しは app/tools/make-ogp.py。
　文言やロゴを変えたら、必ず作り直してください。

■ 追加・削除したとき

追加：ページ側から参照して初めて意味を持ちます。置くだけでは表示されません。
削除：どこからも参照していないことを確かめてから消してください。

　cd app && grep -rn "ファイル名" src/ index.html

　何も出なければ未参照です。
